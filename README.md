# analysis_RBAC_k8
Программное решение для анализа RBAC в Kubernetes. 

Он анализирует Roles, Clusterroles, Rolebindings и Clusterrolebindings для каждого субъекта (User, Group, ServiceAccount), отображает весь список прав, а также указывает, являются ли они глобальными или используются в рамках namespace, и анализирует, является ли роль опасной.

Функциональность программы:
- парсинг файлов YAML/JSON, содержащих Roles, Clusterroles, Rolebindings и Clusterrolebindings
- хранение списка опасных правил в виде конфигурационного файла с возможностью добавления собственных правил
- возможность выводить все права или только опасные
